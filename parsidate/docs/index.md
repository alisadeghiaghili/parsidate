## Main Features

- Dual calendar support (Jalali and Gregorian)
- Rich parsing, formatting (English/Persian)
- Date arithmetic, comparison, rounding
- Intervals: Period, Duration, Interval
- Timezone handling
- Pandas integration: Date dimension tables

## API Modules

- **core**: JalaliDate, GregorianDate, conversion
- **parsers**: String/date parsing
- **formatting**: Flexible date formatting
- **operations**: Math, comparison, range, rounding
- **intervals**: Period, Duration, Interval
- **timezone**: tzinfo, conversion, localization
- **dimdate**: Analytics/Pandas dimension table
- **utils**: Calendar and leap year logic
