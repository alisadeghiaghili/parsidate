---

**[1] PREREQUISITES**

- Python 3.8+
- Recommended: virtualenv for isolated environments

---

**[2] CLONE & INSTALLATION**

Clone the repository:

git clone https://github.com/your-username/parsidate.git
cd parsidate

Install requirements (development):

pip install -r requirements.txt
pip install -r dev-requirements.txt

Or minimal install for library only:

pip install .

---

**[3] VERIFY INSTALLATION**

Test import in Python shell:

from parsidate.core import JalaliDate, GregorianDate

---

**[4] RUNNING TESTS**

Run all tests (requires pytest):

pytest tests/ -v --cov=parsidate


Optional: run type checker and code style tools

mypy parsidate/
flake8 parsidate/
isort parsidate/
black --check parsidate/

---

**[5] EXAMPLES AND DOCS**

- Example scripts in `/examples`
- API usage in `USAGE_GUIDE.md` and `README.md`
- For interactive usage: Jupyter notebooks under `/notebooks` (if present)
- Full docstrings in every class/module

---

**[6] BUILDING FOR DISTRIBUTION**

python -m build


Creates `dist/` directory containing `.whl` and `.tar.gz` distribution files.

---

**[7] PUBLISH TO PYPI**

See `PUBLISHING_GUIDE.md` for details.

---

**[8] TROUBLESHOOTING**

- Make sure Python >= 3.8
- If you see `ModuleNotFoundError`, check PYTHONPATH or run install again.
- For Windows: Use `python` instead of `python3` if necessary.

---

**[9] ENVIRONMENT MANAGEMENT**

(optional, but recommended)

python -m venv .venv
source .venv/bin/activate # Linux/Mac
.venv\Scripts\activate # Windows
