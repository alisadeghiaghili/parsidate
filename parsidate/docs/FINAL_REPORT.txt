SUMMARY

ParsiDate is a professional Python library for robust handling of Persian (Jalali) and Gregorian dates, featuring conversion, parsing, formatting, arithmetic, intervals, timezone management, and data analytics integration. The toolkit provides a comprehensive, type-safe, and fully tested modular API.

---

KEY MODULES AND FEATURES

- core        — JalaliDate, GregorianDate base classes & conversion utilities
- parsers     — Advanced parsing (string to date classes, multi-format, localization)
- formatting  — Full, short, ISO, custom formatting (English & Persian support)
- operations  — Arithmetic (days, weeks, months, years), comparison, rounding
- intervals   — Period, Duration, Interval abstraction and math
- timezone    — Pytz-compatible get/convert/localize, full DST, offset handling
- generator   — Date sequence/range generator utilities
- dimdate     — Pandas-based dimensional date table generator
