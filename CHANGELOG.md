# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2024-11-08

### Added
- Initial release of ParsiDate
- Complete Jalali (Persian/Solar Hijri) calendar support
- Complete Gregorian calendar support
- Intuitive date parsing functions
- Date arithmetic operations
- Duration, Period, and Interval classes
- Timezone support and conversion
- Dimension Date table generator
- Full type hints and mypy support
- Comprehensive test suite
